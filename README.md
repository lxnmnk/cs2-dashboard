# CS2 Price Dashboard — project by lxnmnk

Панель отслеживания и вычисления прибыльных скинов CS2 по пяти источникам цен: **CSFloat**, **Buff163**, **Youpin898**, **CS.Money**, **Skinbux**.

## Источники цен

- **CSFloat, Buff163, Youpin898** — через [cs2.sh](https://cs2.sh/docs/introduction), один API-ключ, один запрос на все ~47 000 предметов сразу (`GET /v1/prices/latest`).
- **CS.Money** — публичный API `instantsell/price/all`, ключ не нужен. У них стоит защита Cloudflare, которая блокирует обычные запросы из Node.js. Приложение сначала пробует быстрый прямой запрос, а если его заблокировали (403) — автоматически переключается на headless-браузер (Chromium через `puppeteer`), который Cloudflare пропускает как настоящий браузер. Никаких действий от вас не требуется. Даёт только цену мгновенного выкупа (сторону продажи), поэтому как источник покупки не используется.
- **Skinbux** — `https://api.skinbux.com/v1/prices`, ключ передаётся в заголовке `x-api-key`. Цены в ответе приходят в центах — приложение само переводит их в доллары; предметы, которые skinbux сейчас не принимает к покупке/продаже, корректно помечаются как недоступные.

## 0. Установите Node.js (если ещё не установлен)

Скачайте LTS-установщик для Windows: https://nodejs.org/dist/v24.11.1/node-v24.11.1-x64.msi

Запустите `.msi`, везде «Next» с настройками по умолчанию. После установки **перезагрузите компьютер** (или закройте все окна консоли) — иначе Windows не увидит команду `node`.

Проверка: откройте новое окно PowerShell/CMD и введите `node -v` — должна показаться версия.

## Установка

```bash
cd cs2-dashboard
npm install
copy .env.example .env
```

**Важно:** `npm install` скачивает ещё и Chromium (~200-300 МБ) — он нужен, чтобы обходить защиту cs.money от ботов. Первая установка может занять несколько минут в зависимости от скорости интернета.

Откройте `.env` и впишите свои ключи:

```
CS2SH_API_KEY=ваш_ключ_cs2sh
SKINBUX_API_KEY=ваш_ключ_skinbux
```

cs2.sh: ключ можно получить в Discord cs2.sh (Sign up → открыть тикет). На Developer-плане доступен `GET /v1/prices/latest`, которого приложению достаточно.
Skinbux: ключ выдают партнёрам, см. документацию на https://documenter.getpostman.com/view/4148020/2sAXjF8uax.

CS.Money ключа не требует.

## Запуск

Проще всего — двойной клик по `start.bat`. Он сам проверит Node.js, создаст `.env` при первом запуске, поставит зависимости и поднимет сервер.

Вручную:
```bash
npm start
```

Откройте http://localhost:3000

Сервер сразу подгружает цены при старте и далее обновляет их автоматически каждые `refreshIntervalMinutes` минут (по умолчанию 5, задаётся в `config.json`). Кнопка «Обновить сейчас» в интерфейсе форсирует внеплановое обновление. Если один из источников временно недоступен (например, cs.money) — остальные всё равно подгрузятся, ошибка покажется только если вообще ничего не удалось загрузить.

## Панель управления (в интерфейсе)

- **Поиск по названию** — фильтр по подстроке в market_hash_name
- **Мин. прибыль $ / %** — пороги отсечения для вкладки «Только прибыльные (топ)»
- **Убрать StatTrak™** — чекбокс, скрывает все StatTrak-предметы
- **Цена от $** — показывает только предметы дороже указанной суммы (по самой низкой цене покупки среди источников)
- **Купить на / Продать на** — по умолчанию «любой» (автоматический поиск лучшей связки). Можно зафиксировать конкретную площадку с одной или обеих сторон — тогда прибыль пересчитывается именно под эту связку
- **Макс. спред Youpin898 % / Buff163 %** — скрывает предметы с большой разницей между ask и bid на этой площадке (обычно признак низкой ликвидности); пусто = без ограничения
- **Показывать: топ / все предметы** — переключение выборки

Заголовки столбцов **«Прибыль $»** и **«Прибыль %»** кликабельны — сортировка по возрастанию/убыванию (стрелка ▲/▼ показывает направление). Клик по любой цене (csfloat/youpin898/buff163/cs.money/skinbux) открывает поиск этого предмета на соответствующей площадке в новой вкладке.

## Как считается прибыль

Движок (`pricingEngine.js`) перебирает пары «купить на источнике A → продать на источнике B» (или использует зафиксированную пару, если выбрана вручную) и берёт связку с максимальной прибылью:

```
цена_покупки = ask_источника_A * (1 + комиссия_покупки_A)
цена_продажи = bid_источника_B * (1 - комиссия_продажи_B)
прибыль_$    = цена_продажи - цена_покупки
прибыль_%    = прибыль_$ / цена_покупки * 100
```

⚠️ Экстремальные значения прибыли (сотни процентов) почти всегда означают не реальную возможность заработка, а неликвидный предмет или устаревшую/единичную цену на одной из площадок — проверяйте такие находки вручную перед сделкой.

## Настройка параметров

Все параметры — в `config.json`:

- `sources.<name>.buyFee` / `sellFee` — комиссии площадок (замените на реальные, дефолтные — ориентировочные; у skinbux — 0, их маржа уже заложена в разницу buy/sell)
- `sources.<name>.enabled` — включить/выключить источник
- `marketUrls.<name>` — шаблон ссылки для клика по цене (`{name}` = market_hash_name). Если площадка сменит формат поиска — правьте здесь, без кода
- `filters.minProfitUsd` / `minProfitPercent` — пороги отсечения по умолчанию
- `filters.maxResults` — сколько строк показывать в топе
- `filters.excludeStatTrak` / `minPrice` / `maxYoupinSpreadPercent` / `maxBuffSpreadPercent` — дефолты для соответствующих фильтров в интерфейсе
- `refreshIntervalMinutes` — частота автообновления

Изменения в `config.json` применяются при перезапуске сервера, либо через `POST /api/config` (тот же формат JSON) без рестарта.

## Обновление до новой версии

1. Скачайте новый `cs2-dashboard.zip`
2. Перетащите его на `update.bat` в папке проекта (или сохраните в папку «Загрузки» — тогда `update.bat` найдёт его сам при обычном двойном клике)
3. Дождитесь окончания — скрипт распакует архив поверх текущей папки и прогонит `npm install`, если менялись зависимости

Ваш `.env` (с ключами) и папка `node_modules` при этом не трогаются.

## Структура проекта

```
cs2-dashboard/
├── server.js            # Express-сервер: кэш, автообновление, API
├── pricingEngine.js      # Слияние цен источников, расчёт прибыли, фильтры
├── itemName.js            # Разбор market_hash_name на название/качество
├── config.json           # Комиссии, ссылки на площадки, фильтры, интервал обновления
├── start.bat              # Проверка Node.js + запуск сервера одним кликом
├── update.bat             # Накатывание нового архива поверх текущей папки
├── sources/
│   ├── cs2sh.js           # csfloat + buff163 + youpin898 (нужен CS2SH_API_KEY)
│   ├── csmoney.js         # cs.money (без ключа, с обходом Cloudflare через puppeteer)
│   └── skinbux.js         # skinbux (нужен SKINBUX_API_KEY)
└── public/                # Веб-интерфейс (HTML/CSS/JS)
```
