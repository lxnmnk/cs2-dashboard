# Логотипы способов оплаты

Сюда кладутся файлы логотипов — они появятся на главной странице сами.
Имена строго такие (иначе плашка останется текстовой):

    mono.svg  privat24.svg  abank.svg  binance.svg  usdt.svg  usdc.svg

Требования:
- SVG (можно PNG, тогда поменяй расширение в сборщике страницы);
- высота на странице 20px, так что рисунок должен читаться в этом размере;
- логотипы на светлом фоне на тёмной странице теряются — бери версии для
  тёмного фона или с прозрачностью.

Файла нет — страница просто покажет название в фирменном цвете, ничего не
сломается.
